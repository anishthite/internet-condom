Plain-English tweet filter (Chrome MV3)

main · worktree ~/workspace/internet-condom · 2026-09-28 · status ready-for-review · blast low

Summary

Goal
Hide tweets matching a user-written plain-English filter on x.com/twitter.com.
Source
Tweet text from [data-testid="tweetText"]; verdicts from TypeSafe Jev noul questions.
Surface
Popup (filter, API key, enabled toggle); content script on x.com + twitter.com.
Schema
chrome.storage.local keys: enabled, filter, apiKey.
Open Qs
0.

API contract

POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer <apiKey>
{
  "model": "jev-latest",
  "state": "Tweets from a Twitter/X timeline.",
  "questions": {
    "<statusId>": { "type": "noul",
      "instructions": { "tweet": "<text>",
        "question": "Does `tweet` match this filter? Filter: <filter>" } } }
}
→ answers[<statusId>].noul ∈ [0,1]; hide when noul > 0.5

Algorithm

  1. MutationObserver (childList+subtree, 100ms debounce) scans for article[data-testid="tweet"].
  2. Skip seen (data-ic-seen) and textless tweets; key by status id from time link, fallback to text.
  3. Queue unseen; flush at 8 queued or 300ms idle → one Jev call, one noul question per tweet.
  4. Cache verdict in-memory; display:none when noul > 0.5; leave visible on API error.
  5. On filter/enabled storage change: clear cache, unhide all, rescan.

Decisions

IDChoiceRationale
D-001TypeSafe Jev noul per tweet, batched 8/call.User-picked backend; classification-only model fits; batching shares state cost.
D-002API calls in background SW, not content script.Content-script fetches inherit page CORS; SW + host permission avoids it.
D-003Hide via display:none, no placeholder UI.Simplest; X's virtualized list tolerates it.
D-004Tweet text embedded in question instructions, not state.Documented backtick reference; lets one state serve N tweets.

Tradeoffs

IDPicked over RejectedReason
T-001In-memory verdict cache over persisted storage.local cache.Reload re-judges a few tweets; costs ~nothing at Jev prices. Add if cost shows up.
T-002Fixed threshold 0.5 over popup slider.YAGNI; one constant to change.
T-003Plain JS, no bundler/npm.5 files, load-unpacked just works.

Assumptions

  • A-001 X keeps data-testid="tweet"/tweetText and /status/<id> time links; breakage = tweets stay visible, no crash.
  • A-002 User has a TypeSafe API key (TYPESAFE_API_KEY).

Reversibility

R-001 low — new repo, additive only; revert = delete files or toggle Enabled off.

Followups

  • L-001 Threshold slider + batch-size config if 0.5 misfires.
  • L-002 Persisted verdict cache keyed by status id if API spend matters.
  • L-003 Blur-with-reveal instead of hide, if user wants to audit blocked tweets.

Definition of done

  • node --check passes on all JS; manifest parses.
  • Load unpacked → set key + filter + enable → matching tweets hide on x.com (needs user's key; manual).
